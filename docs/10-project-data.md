# 10. 保存とデータ

## 自動保存

作業内容は **ブラウザの中に自動保存** されます。閉じて開き直すと、同じ状態から再開できます。

| 保存されるもの | 置き場所 |
|---|---|
| プロジェクト（歌詞・テロップ・全トラックの記録・設定） | ブラウザの localStorage |
| 素材（曲・背景・立ち絵・MMD モデル・ポーズ / モーション / カメラ VMD） | ブラウザの IndexedDB |
| 読み込んだプラグイン | ブラウザの localStorage |

- 同じブラウザ・同じアドレス（例：`http://localhost:5178`）でだけ残ります。別のブラウザや別のアドレスで開くと空になります。
- ブラウザの「閲覧データの削除」で消えます。大事なプロジェクトは .json でも保存しておいてください。

## .json で保存・読み込み

左パネル「プロジェクト」の **保存 (.json)**（`Ctrl+S`）/ **読み込み**。.json をウィンドウにドロップしても読み込めます。

- .json に入るのは **プロジェクトの中身だけ** で、素材のファイル本体は入りません。
- 同じブラウザなら、素材はブラウザに保存されているので、読み込むとそのまま使えます。
- 別のブラウザや別の PC に移すときは、.json を読み込んだあと、曲・背景・立ち絵・MMD モデルを入れ直してください（見つからない素材は名前が表示されます）。
- 立ち絵は、左パネルのカード（⚠ 未読込）の **「差し替え」** で入れ直すと、録音した切替がそのまま使えます。「＋ 立ち絵を追加」で入れると別の立ち絵になります。

## 新しく始める・デモ

- **空のプロジェクトから**：上部バー右の「新規」（左パネル「プロジェクト → 新規」でも）。歌詞は見本に戻り、記録・曲・立ち絵・背景は外れます（元に戻せないので、残すなら先に保存 (.json)）。
- **デモを開く**：左パネル「プロジェクト → デモを開く」。いまのプロジェクトがデモ（曲・立ち絵入り）に置き換わります（`Ctrl+Z` で戻せます）。初めて開いたときも、このデモが開きます。
- **タイミングだけやり直す**：左パネル「歌詞 → タイミング全消去」（全トラックの記録を消し、素材と歌詞の文章は残す）
- **トラック1本だけ**：タイムライン右上「トラック消去…」

## 古いデータ

アプリを更新しても、古いプロジェクトは自動で新しい形式に移し替えて読み込みます。
