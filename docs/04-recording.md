# 4. トラックと録音

## MTR の考え方

MV の要素は **7本のトラック** に分かれていて、1本ずつ録音して重ねていきます（マルチトラックレコーダーのように）。

| トラック | 記録されるもの |
|---|---|
| **歌詞** | 文字ごとの出現タイミング、歌詞スタイルの切替、歌詞のエフェクト・モーション |
| **テロップ** | テロップの出現時刻と長さ、テロップのエフェクト・モーション |
| **立ち絵** | キャラの切替、位置、エフェクト（影・縁取りなど）、モーション（揺れ方） |
| **カメラ** | フレーミング（全身・バスト・アップ…）、カメラの動き |
| **FX** | フラッシュ・シェイク・グリッチなどのワンショット演出 |
| **ビジュアル** | オーディオビジュアライザーの種類・位置・色・大きさ・重なり |
| **ルック** | ルックスタイル、背景、パレット、背景の明るさ |

たとえば「まず歌詞を叩く → 次に立ち絵の切替を録る → カメラを録る → FX を足す」と、1本ずつ何周でも重ねられます。

## 録音の手順

1. 上部のタブ（または `Tab`）で録音するトラックを選ぶ。タイムラインの行の名前をクリックしても選べる。
2. `Shift+R` で REC。再生が始まる。
3. キーパネルのキーを曲に合わせて押す。
4. `Shift+R`・`Esc`・停止（▶ボタン。歌詞・テロップ以外のトラックでは `Space` も）で REC 終了。

- **REC 中は選んだトラックにだけ記録** されます。ほかのトラックのキーは押せません（トラックも切り替えられません）。
- REC を止めると、そのまま REC は終わります。続きを録るときは、もう一度 `Shift+R`。

## 重ね録り と 上書き

キーパネルの上で切り替えます。**既定は重ね録り** です。

| 方式 | 動作 |
|---|---|
| **重ね録り**（既定） | 既存の記録はそのままに、新しく押した分を足す |
| **上書き** | REC した区間の、そのトラックの記録を消して差し替える（パンチイン） |

- 同じ時刻・同じ種類の記録（例：同じ瞬間の「位置」）は、重ね録りでも新しい方に置き換わります。
- 歌詞の文字のタイミングは1文字に1つなので、叩き直すとどちらの方式でも置き換わります（[3. 歌詞](03-lyrics.md#叩き方)）。

## 試し弾き

REC せずに再生中にキーを押すと、**画面には出るが記録されない** 「試し弾き」になります。どのキーがどう見えるか確かめてから REC する、という使い方ができます。
停止すると試し弾きの分は消えます。停止中にキーを押しても何も起きません（要素を選んでいる場合を除く → [5. タイムラインで編集](05-editing.md#キーで書き換える)）。

## 取り消し

| 操作 | 取り消す範囲 |
|---|---|
| REC 中に `Backspace` | 直前の1回の入力 |
| REC 後に `Ctrl+Z` | テイク（1回の REC）まるごと |
| `Ctrl+Shift+Z` / `Ctrl+Y` | やり直し |

## 停止したときの動き

上部バーの ▶ の横のボタンで切り替えます（プロジェクトに保存されます）。

| 設定 | 動作 |
|---|---|
| **↩ 開始位置に戻る**（既定） | 停止すると、再生・REC を始めた位置に戻る。曲の終わりまで再生して止まったときも戻る |
| **■ その場で止める** | 止めた位置で止まる |

「戻る」だと、同じ区間を何度でも録り直せます。再生中にタイムラインをクリックして移動すると、そこが新しい戻り先になります。

## 再生速度（練習用）

上部バーの `1×` で 0.5 / 0.75 / 1 / 1.25 / 1.5 倍を選べます。

- **音程はそのまま** 速さだけ変わります。各速度の初回だけ準備に数秒かかります（その間は「準備中」と表示）。
- 遅くして叩いても、**記録は曲の時間で正しく** 入ります。入力遅延補正や長押しの長さも速度に合わせて換算されます。
- 書き出しには影響しません。保存もされません（開き直すと 1×）。

## 拍への吸着

- **イベントスナップ**（左パネル「入力」、既定 1/2 拍）：立ち絵・カメラ・FX・ビジュアル・ルック・歌詞スタイル・エフェクト・モーションの記録を拍に吸着させます。オフ・1拍・1/2拍・1/4拍。
- **歌詞クオンタイズ**：歌詞の文字タイミング用（既定オフ）。
- **メトロノーム**（左パネル「楽曲」）：再生中にクリック音を鳴らします。

## 長押しで長さを決める

- **FX**：⏵ の付いた FX は、押している長さだけ続きます（短く押すと既定の長さ）。
- **テロップ**：`Space` を長押しすると、その長さだけ表示されます（0.3 秒以下の短押しは型の既定の長さ）。

## 固定とオート

何も録音していない区間は **固定** です：1人目の立ち絵が中央・全身・静止・エフェクトなし、カメラ固定、背景は1枚目、ビジュアライザーなし。

立ち絵やカメラを **自動で動かしたい** 区間では、そのトラックで「オート」のキーを録音します（立ち絵 `-` `G` `U` `M`、カメラ `K` `O` など）。そこから次の記録までは自動演出（ショットの切替・ズーム・キャラの入れ替え）になります。

- 自動演出の切替の速さ：左パネル「ルック → オート演出の間隔」（速い ×0.5〜とてもゆっくり ×4）
- 自動演出の乱数：左パネル「ルック → 演出シード」（🎲 で変える）
- 自動演出の癖（カット割りか滑らかか、よく使うショット、キャラのエフェクト）はルックスタイルごとに違います。
