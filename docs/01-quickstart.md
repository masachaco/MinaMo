# 1. はじめての1本（10分）

曲を入れて、歌詞を叩いて、MP4 にするところまでを一気にやってみます。細かい設定はあとの章で説明します。

## 用意するもの

- **ブラウザ**：Chrome か Edge（動画の書き出しに WebCodecs を使うため）
- **曲**：mp3 / wav / ogg / m4a など
- **歌詞**：テキスト
- あれば：**立ち絵**（背景が透明な PNG）、**背景**（画像か動画）

## 起動する

アプリを手元で動かす場合（Node.js が必要）：

```bash
npm ci           # 初回だけ。依存パッケージを package-lock.json どおりに入れる
npm run dev      # http://localhost:5178 を開く
```

## まずはデモを見る

初めて開くと、**デモのプロジェクト**（曲・歌詞・立ち絵・演出がひととおり入ったもの）と **チュートリアル** が開きます。
再生位置は、歌が始まる少し前（22.5秒）から始まります。
画面の一部が明るくなり、吹き出しに「次にやること」が出ます。その通りに操作すると次へ進みます。

1. デモを再生して見る
2. タイムラインとトラックの見方
3. 歌詞トラックで REC して、歌に合わせて `Space` で歌詞を1文字ずつ出す
4. 再生して確かめる
5. `Enter` で1行まとめて出す
6. REC して `Q`〜`T` で歌詞にエフェクトを付ける
7. 立ち絵トラックで、数字キーで立ち絵を切り替える・`A` `S` `D` `F` で位置を変える
8. FX トラックで、フラッシュなど画面全体の FX を出す
9. カメラトラックで、フレーミングやカメラの動きを切り替える
10. 止めたままの編集・書き出しの紹介
11. 「新規」でデモを片付けて、まっさらから始める

吹き出しの「スキップ」でいつでも終われます。もう一度見るときは右上の **「？」**（左パネル「プロジェクト → チュートリアル」でも）。

自分の曲で作るときは、右上の **「新規」**（左パネル「プロジェクト → 新規」でも同じ）で空のプロジェクトにしてから始めます（デモはいつでも「プロジェクト → **デモを開く**」で戻せます）。

## ステップ1：曲と素材を入れる

曲のファイルをウィンドウに **ドロップ** します（左パネル「楽曲」の枠をクリックして選んでも可）。
立ち絵（透明 PNG）や背景画像も同じようにドロップできます。透明な PNG は立ち絵、それ以外の画像は背景に自動で振り分けられます。

## ステップ2：BPM を合わせる

左パネル「楽曲」で **BPM** を入力します。分からなければ、曲に合わせて `TAP` ボタンを4回以上クリックすると推定できます。
次に **1拍目**：曲の最初の小節の頭まで再生して止め、「現在位置」ボタンを押します。拍の点滅（右上の四角）が曲と合えば OK です。

> 拍が合っていると、FX やカメラが拍に吸着し、演出が気持ちよくハマります。

## ステップ3：歌詞を書く

左パネル「歌詞」の欄に、**1行 = 1フレーズ** で歌詞を書きます。

```
夜を/駆け抜けて | Run through the night
君の声が/聞こえる
```

- `/` で区切るとチャンク（単語）になります（書かなくても自動で区切られます）。
- `|` の後ろはサブテキスト（訳など）です。

## ステップ4：叩いて録音する（REC）

1. 上部のタブで **歌詞** を選びます（`Tab` でも切替）。
2. 歌い出しの少し前にシークして、`Shift+R` で **REC** を始めます。再生が始まります。
3. 歌に合わせてキーを押します。押した瞬間に歌詞が出ます。
   - 歌に合わせて **1文字ずつ** 表示したい場合は `Space`
   - **1行ずつ** 表示したい場合は `Enter`
   - 単語（チャンク）ごとに表示したい場合は `N`
4. `Esc` か `Shift+R` で REC を終えます。止めると REC を始めた位置に戻ります。

失敗したら `Ctrl+Z` でテイクごと取り消せます。REC 中の `Backspace` は直前の1回だけ取り消します。
叩き直すときは、同じ場所からもう一度 REC すれば上から入れ直せます。

## ステップ5：見た目を変える

- **歌詞スタイル**：歌詞トラックで REC 中（または再生中に試し弾き）に数字キー `1`〜`7` を押すと、その時点から歌詞の動きが変わります。
- **ルック**（画面全体の雰囲気）：左パネル「ルック」で選べます。
- **立ち絵**：立ち絵トラックで数字キーを押すとキャラが切り替わります。

どれも REC 中に押した分だけが記録されます。REC せずに再生中に押すと「試し弾き」で、見た目だけ変わって記録はされません。

## ステップ6：書き出す

右上の **「書き出し」** を押し、形式（MP4 / WebM）と範囲を選んで「書き出し開始」。
1フレームずつ描いて書き出すので、PC の性能によっては曲の長さより時間がかかります。終わると動画ファイルがダウンロードされます。
