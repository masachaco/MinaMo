# 8. 立ち絵と MMD

キャラクターは、画像の **立ち絵**（透過 PNG）か、**MMD モデル**（PMX / PMD）で出せます。どちらも立ち絵トラックで同じように切り替えられます。

## 画像の立ち絵

透明部分のある PNG をドロップすると立ち絵として追加されます（左パネル「背景・立ち絵」の枠からも追加可）。透明な余白は自動で切り詰めます。

左パネルで立ち絵ごとに調整できます：

| 項目 | 内容 |
|---|---|
| キー番号 | 立ち絵トラックで押す数字（一覧の順番。`1`〜`9` まで） |
| 使う | オフにするとキーにも自動演出にも出ない |
| 反転 | 左右反転 |
| 顔 | 顔の位置（点線）。アップやバストのとき、ここが中心になる |
| 大きさ | 0.5〜1.6 倍 |
| 横 / 縦 | 画面上の位置のずらし（ダブルクリックで0、「位置リセット」で両方0） |
| 差し替え | 画像だけを入れ替える（ボタン、またはカードに画像をドロップ）。録音した切替・エフェクト・顔の位置・大きさ・位置・反転はそのまま。`Ctrl+Z` で元の画像に戻せる |

表情違いの差分に入れ替えたいときや、見つからない（⚠ 未読込）立ち絵を入れ直すときは「差し替え」を使います。「＋ 立ち絵を追加」やウィンドウへのドロップは、別の新しい立ち絵になります。
顔の位置は画像の高さに対する割合で覚えているので、構図の違う画像に差し替えたときは「顔」を合わせ直してください。

## 立ち絵トラック

| キー | 内容 |
|---|---|
| `1`〜`9` / `0` / `-` | キャラ切替 / 隠す / オート |
| `A` `S` `D` `F` / `G` | 位置：左・中央・右・2人（2人目も出す）/ オート |
| `Q`〜`T` / `Y` / `U` | エフェクト（トグル）：影・縁取り・グロー・スライス・シルエット / なし / オート |
| `Z`〜`N` / `M` | モーション：静止・バウンス・ゆらゆら・ふわふわ・ジャンプ・ブルブル / オート |
| `I` `O` `P` `[` `]` / `J` `K` `L` `H` | プラグインで足したエフェクト / モーション |

キャラの切替はクロスフェードで、何も録音していない区間は1人目が中央・全身・静止です（[4. トラックと録音](04-recording.md#固定とオート)）。
エフェクトとモーションは歌詞・テロップにも同じものがあります（[3. 歌詞](03-lyrics.md#エフェクトとモーション)）。重ねたエフェクトは、トグルした順番に関係なく「グロー → 影 → 縁取り」の順（奥から）に重なります。

## MMD モデル

### モデルを入れる

PMX / PMD と、テクスチャの入った **フォルダごと** 入れます。

- フォルダをウィンドウにドロップするか、左パネルの「＋ MMD モデル（フォルダを選択）」。
- フォルダに複数のモデル（衣装違いなど）があると、どれを使うか選ぶ画面が出ます。
- 使うのはモデル本体と画像ファイル（bmp / png / jpg / tga / sph / spa など）だけで、psd や説明書は取り込みません。
- 取り込んだモデルはブラウザ内に保存されます（プロジェクトの .json には入りません）。

入れると、そのモデルの **「基本姿勢」** の立ち絵が1つできます。

### ポーズとモーション

モデルの枠の「＋ ポーズ / モーション」で **.vpd（ポーズ）** と **.vmd（モーション）** を追加します（モデルの枠やウィンドウへのドロップでも可）。

- **1ファイル = 1つの立ち絵** になります（例：「基本姿勢」「手を振る」「ダンス」）。キーパネルにはポーズ名で並び、普通の立ち絵と同じく数字キーで切り替えます。
- 同じモデルの立ち絵どうしの切替は、ポーズがなめらかにつながります（2枚が重なって見えることはない）。
- モーションは、その立ち絵に **切り替わった時点から** 再生され、ループします。
- 新しく追加した立ち絵は、そのモデルの最初の立ち絵の大きさ・位置・反転を引き継ぎます。

### 立ち絵ごとの設定（MMD）

画像の立ち絵と同じ項目（顔・大きさ・横 / 縦・反転・使う）に加えて：

| 項目 | 内容 |
|---|---|
| **回転Y / X / Z** | 体の中心を軸に、向き（Y）・前後の傾き（X）・左右の傾き（Z）を −180°〜180° で。ダブルクリックで0。同じモデルの立ち絵間の切替では回転もなめらかにつながる |
| **テンポ**（モーション） | **拍に合わせる**（既定。1ループが BPM のちょうど何拍かになるよう速さを調整）/ 元の速さ。さらに ×0.5 / ×1 / ×2 |
| **口パク** | オンにすると、曲の歌声の帯域の大きさで口（モーフ「あ」）が動く。曲全体の音に反応するので楽器でも動く |
| **カメラ** | カメラ VMD を付ける（下記） |

### 揺れもの（髪・スカート）

モデルの枠の「揺れもの（髪・スカート）」で、髪とスカートの揺れをオン / オフします（既定オン）。

- スプリングボーンによる近似です。MMD 本来の物理演算ほど正確ではありません。
- シークしたときは直前 0.5 秒ぶんを計算して落ち着かせるので、**シークしても書き出しても毎回同じ結果** になります。

### カメラ VMD

カメラ VMD（カメラの動きだけのファイル）を立ち絵に付けると、**その立ち絵の間は MMD のカメラワークで全画面表示** になります。

- モーションとカメラ VMD を一緒に追加すると、カメラはそのモーションの立ち絵に自動で付きます。あとからは立ち絵カードの「＋ カメラ VMD」、外すときは「外す」。
- カメラの時間はモーションと同じ（切り替えた時点から、同じテンポで）です。
- その間はカメラトラックのズームやパンはかかりません。

### 知っておくこと

- モデルは全身が入る固定の枠で描くので、大きく動くモーションでは手足が枠の端で切れることがあります。大きさ・位置で調整してください。
- 立ち絵のキー（とダブルクリックのメニュー）は `1`〜`9` までなので、キャラとポーズは合わせて9つまでです。10個目以降は、立ち絵の記録を選んでインスペクタの「値」で選べます。
- 3D を毎フレーム描くので、書き出しは画像の立ち絵より時間がかかります。
- **モデル・モーションの利用規約** を必ず確認してください（キャラクターのライセンス、改変や公開の可否、クレジットの表記など）。
