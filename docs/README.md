# MinaMo マニュアル

**MinaMo（みなも）** は「水面」と **M**us**I**c **MO**vie から。水面に石を落とすと波紋が広がるように、キーを叩いた瞬間に歌詞やエフェクトがその場で広がる——そんな手ざわりで MV を作ることから名付けました。

音楽に合わせて **キーを叩くだけ** で、モーショングラフィックスのリリックMVを作るブラウザアプリのマニュアルです。
歌に合わせてキーを押すと、歌詞が1文字ずつ（`Space`）や1行ずつ（`Enter`）表示されます。VJ のようにスタイル・FX・カメラもキーで切り替え、トラックごとに重ね録りして仕上げます。

## 用語

| 用語 | 意味 |
|---|---|
| **トラック** | 歌詞・テロップ・立ち絵・カメラ・FX・ビジュアル・ルックの7本。録音はトラックごと |
| **REC** | 選んだトラックに記録する録音状態（`Shift+R`） |
| **重ね録り／上書き** | REC で既存の記録に足すか、録った区間を差し替えるか（既定は重ね録り） |
| **試し弾き** | REC せずに再生中にキーを押すこと。画面には出るが記録されない |
| **Space / Enter** | 歌詞トラックの REC 中、歌に合わせて1文字ずつ表示したい場合は `Space`、1行ずつ表示したい場合は `Enter`（単語ごとなら `N`） |
| **チャンク** | 歌詞の1行を `/` や自動分割で区切った単位（単語くらい） |
| **歌詞スタイル** | 歌詞の文字の動き（KINETIC など） |
| **ルック** | 画面全体の世界観（背景演出・ポストエフェクト・カメラの癖・切替のトランジション） |
| **エフェクト / モーション** | 歌詞・テロップ・立ち絵にかける効果（影・グローなど。トグルで重ねがけ）と動き（バウンス・ゆらゆらなど。1つ選ぶ）。3つで共通 |
| **オート** | 立ち絵やカメラを自動で動かす演出。既定はオフで、「オート」を録音した区間だけ動く |
