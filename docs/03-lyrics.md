# 3. 歌詞

## 書き方

左パネル「歌詞」の欄に書きます。

```
# この行はコメント（表示されない）
夜を/駆け抜けて | Run through the night
君の声が/聞こえる
止まらない/鼓動の/リズム
```

| 書き方 | 意味 |
|---|---|
| 1行 | 1フレーズ（画面に一度に出るまとまり） |
| `/` | チャンク（単語）の区切り。`N` キーで1チャンクずつ出せる。行を積むスタイルでは行の区切りにもなる |
| `\|` の後ろ | サブテキスト（訳・読み・英語など）。表示の仕方はスタイルによる |
| `#` で始まる行 | コメント |
| 空行 | 無視 |

- `/` を書かなければ自動でチャンクに分けます（日本語は助詞を前の語にくっつけた単語ごと、英語は空白ごと）。「この」「あの」などは次の語とまとめます。
- 文字は書記素（見た目の1文字）単位で数えます。絵文字や濁点付きの文字も1文字です。

### 書き直したときのタイミング

叩いたあとで歌詞を書き直しても、**変えていない行のタイミングはそのまま** 残ります。
同じ位置の行を書き換えた場合は、行の開始と終わりの時刻だけが残り、文字ごとのタイミングは未入力に戻ります。新しく足した行は未入力です。

## 叩き方

歌詞トラックを選んで `Shift+R` で REC し、歌に合わせてキーを押します。
歌に合わせて1文字ずつ表示したい場合は `Space`、1行ずつ表示したい場合は `Enter` を押します。

| キー | こんなとき | 動作 |
|---|---|---|
| `Space` | 歌に合わせて **1文字ずつ** 表示したい | 次の1文字を、押した瞬間に出す |
| `N` | **単語（チャンク）ごと** に表示したい | 次のチャンクの頭に進んで出す（残りの文字は自動の間隔で出る） |
| `Enter` | **1行ずつ** 表示したい | 次の1行の頭に進んで出す（残りの文字は自動の間隔で出る） |
| `X` | 歌詞を消したい | いま表示中の行を消す（その時刻を行の終わりにする） |
| `Backspace` | 押し間違えた | 直前の1回を取り消す |

- 叩いていない文字は、前後の叩いた文字の間や、スタイルごとの間隔で自動的に出ます。全部を `Space` で叩く必要はありません。
- **パンチイン**：ある文字を叩き直すと、それより後ろで「いま叩いた時刻より前」になってしまった文字のタイミングは消えます。途中から録り直すときに、前のテイクの残りが邪魔をしません。
- 歌詞の最後まで叩くと「歌詞の最後に到達しました」と出ます。

## 入力位置

「次に叩くとどの文字が出るか」が **入力位置** です。プレビューの下（プロンプター）に、次の文字がハイライトされます。

| 操作 | 動作 |
|---|---|
| スライダー（文字 / 行 単位を切替） | 入力位置を移動 |
| 行内の文字をクリック | その文字から |
| `↑` `↓` / `Shift+↑` `Shift+↓`（停止中） | 1行 / 1文字ずつ移動 |
| **再生位置に追従**（既定オン） | REC を始めたとき、再生位置より後ろの最初の未入力文字から入力する |
| **⏮ 頭出し** | 入力位置の1小節前へシーク（助走をつけて録り直す） |

入力位置を手で選ぶと「再生位置に追従」はオフになります。
再生位置が、直前に入力済みの歌詞より前にあるまま REC を始めると、警告が出ます（そのまま叩くと前の歌詞とタイミングが前後するため）。

## 行が消えるタイミング

歌詞の行は、次の行が出るまで表示されます。次の行がない場合や間が空く場合は：

- `X` で消す（REC 中）
- インスペクタで行の「明示的な終了」をオンにして時刻を指定
- 何もしなければ、左パネル「入力 → 自動消去」の小節数（既定4小節）で消える

## ぴったり合わせる

| 機能 | 場所 | 使いどころ |
|---|---|---|
| **歌詞クオンタイズ** | 左パネル「入力」 | 叩いた時刻を拍の格子（1拍 / 1/2 / 1/4 / 3連）に吸着させながら録る。既定オフ |
| **一括クオンタイズ** | タイムライン右上 | 録り終えた歌詞をまとめて 4分・8分・16分音符に吸着。`Ctrl+Z` で戻せる |
| **入力遅延補正** | 左パネル「入力」 | 叩いた記録がいつも遅れる／早いとき、ミリ秒で補正（遅れるなら正の値） |
| **再生速度** | 上部バー `1×` | 0.75× などに落として叩く。記録は曲の時間で正しく入る |
| **ドラッグ** | タイムライン | 1文字や1行を後から動かす（[5. タイムラインで編集](05-editing.md)） |

## 歌詞スタイル

歌詞の文字の動き（KINETIC・GLITCH・NEON・EMOTIONAL・POP・IMPACT・MINIMAL と、プラグインで足したもの）です。歌詞の動きだけのスタイルもプラグインで作れます（[12. プラグインを作る](12-plugins.md#歌詞スタイル専用ルック専用)）。

- REC 中に数字キー `1`〜`0` を押すと、その時点から切り替わります。タイムラインの LYRICS の上の帯に区間が出ます。
- 録音していない区間は、左パネル「ルック → 歌詞スタイル」が使われます。
- **1行だけ変える**：タイムラインで行を選び、インスペクタの「この行の歌詞スタイル」を選びます。次の行で元のスタイルに戻ります。
- 歌詞スタイルと画面全体のルックは別々に選べます（例：NEON の世界観に MINIMAL の歌詞）。スタイルの特徴は [6. 見た目](06-look.md#7つのスタイル)。

## エフェクトとモーション

どの歌詞スタイルの上にも重ねられる演出です（立ち絵・テロップと同じもの）。歌詞トラックで録ります（REC 中・試し弾き・ダブルクリックで置く、どれも可）。

| キー | 内容 |
|---|---|
| `Q` `W` `E` `R` `T` / `Y` | エフェクト（トグルで重ねがけ）：影・縁取り・グロー・スライス・シルエット / なし |
| `A` `S` `D` `F` `G` `H` | モーション（1つ選ぶ）：静止・バウンス・ゆらゆら・ふわふわ・ジャンプ・ブルブル |

- エフェクトは **文字** にかかります。ステッカーや帯などの下地はそのままです。
- モーションは、表示中の歌詞全体がテキスト領域の中央を軸に動きます。
- 何も録っていない区間は、エフェクトなし・静止です。
- タイムラインでは LYRICS の下の細い帯に ◆ が並び、エフェクト（上半分）・モーション（下半分）がかかっている区間に色が付きます。
- プラグインで足したエフェクト・モーションは `I` `O` `P` `[` `]` `U` / `J` `K` `L` に入ります（[12. プラグインを作る](12-plugins.md#エフェクトとモーション歌詞テロップ立ち絵)）。

## 行の分かれ方（KINETIC など）

KINETIC のように行を積むスタイルでは、1フレーズを最大3行に分けて表示します。

- `/` を書いた行：**1チャンク = 1行**（書いたとおりに改行）。
- `/` を書かない行：各行の文字数がそろうように自動で分けます。日本語はチャンクの中でも、小さい「っ」の前や送り仮名の途中などを避けて分けます。
- 文字の大きさは1フレーズの中で同じで、短い行は字間を広げて左右をそろえます。

思った通りに改行したいときは `/` を書くのが確実です。
