# 5. タイムラインで編集

録音した記録は、タイムラインとインスペクタで後から直せます。REC しなくても、マウスで要素を置いたり、キーで値を書き換えたりできます。

## 基本操作

| 操作 | 動作 |
|---|---|
| クリック（空いている所） | その時刻へ移動 |
| クリック（要素の上） | 選択。そのトラックが選ばれ、インスペクタに内容が出る |
| ドラッグ | 要素を移動。拍にスナップ（ツールバーの「スナップ」、ドラッグ中 `Alt` で解除） |
| 右クリック | 要素を削除 |
| `Delete` / `Backspace` | 選択中の要素を削除 |
| ホイール | 左右にスクロール |
| `Ctrl+ホイール` / ツールバーの − + | ズーム |
| 「全体」 | 曲全体を表示 |
| 「追従」 | 再生中、再生位置を追いかけてスクロール |
| 中ボタンドラッグ | 表示範囲を動かす |
| 行の名前をクリック | そのトラックを録音対象にする |

### 動かせるもの

| 行 | 要素 | ドラッグすると |
|---|---|---|
| LYRICS | 行（帯） | 行全体（文字のタイミングごと）を移動 |
| LYRICS | 叩いた文字（小さな印） | その1文字だけを前後の文字の間で移動 |
| LYRICS | 行の終わりの印 | 明示的な終了時刻を移動 |
| LYRICS の上の帯 | 歌詞スタイルの切替 | 移動 |
| LYRICS・TELOP の下の帯 | エフェクト・モーションの切替 | 移動 |
| TELOP | テロップの帯 / 帯の右端 | 開始時刻を移動 / 長さを変える |
| その他 | ◆（イベント） | 移動 |

## マウスで置く（ダブルクリック）

トラックの空いている所を **ダブルクリック** すると、その時刻に置けるもののメニューが出ます。REC は要りません。

| 行 | メニューの中身 |
|---|---|
| CHARA・CAMERA・FX・VISUAL・LOOK | キーパネルと同じ項目（キャラ・位置・エフェクト…／フレーミング・動き／FX（キーのないプラグイン FX も）／種類・位置・色…／スタイル・背景・パレット・明るさ） |
| LYRICS（中の段） | 「次の1文字」「次のチャンク」「次の1行」— その時刻より後の最初の未入力文字から |
| LYRICS の上の帯 | 歌詞スタイル |
| LYRICS・TELOP の下の帯 | その要素のエフェクト・モーション |
| TELOP | テロップ一覧（次に出すものが色付き） |

- メニューを **Shift+クリック** すると、カメラのフレーミングはスムーズ移動、ルックのスタイルはトランジションなしで置きます。
- 置いた要素は選択された状態になるので、そのままドラッグで位置を詰めたり、インスペクタで直したりできます。
- スナップがオンなら、置く時刻も拍に吸着します。

## キーで書き換える

要素を選ぶと、そのトラックに自動で切り替わります。**停止中** にキーパネルのキーを押すと、**選んだ要素の値がそのキーのものに変わります**（時刻はそのまま）。

例：
- FX の ◆ を選んで `W` → シェイクに変わる
- 立ち絵の「位置」の ◆ を選んで `A` → 左に変わる
- ルックの ◆ を選んで `Shift+5` → 5番のスタイル・トランジションなしに変わる

`Ctrl+Z` で戻せます。再生中は、キーは従来どおり試し弾き（REC 中は記録）になります。

## インスペクタ

選んだ要素に応じて、右下に編集欄が出ます。

| 選んだもの | 編集できること |
|---|---|
| **歌詞の行** | 開始時刻（行ごと移動）、**この行の歌詞スタイル**、明示的な終了の有無と時刻、「文字タイミングだけ消去」「この行を未入力に」 |
| **叩いた文字** | その文字の時刻（と、行の項目） |
| **テロップ** | 開始、長さ（または型の既定の長さ）、型 |
| **歌詞スタイルの切替** | 時刻、スタイル |
| **FX** | 時刻、FX の種類、長押しの長さ（秒） |
| **立ち絵・カメラ・ビジュアル・ルックの記録** | 時刻、種類、値（エフェクトは複数選択、カメラのフレーミングは「スムーズに移動」、ルックのスタイルは切替のトランジション） |
| **歌詞・テロップのエフェクト・モーション** | 時刻、種類（エフェクト / モーション）、値（エフェクトは複数選択） |

時刻の ▶ ボタンでその時刻へ移動します。

## まとめて直す

| 機能 | 場所 |
|---|---|
| **一括クオンタイズ** | タイムライン右上。4分・8分・16分音符を選ぶと歌詞タイミングがまとめてその格子に吸着 |
| **トラック消去** | タイムライン右上。歌詞タイミング・歌詞スタイル・歌詞のエフェクト・モーション・テロップ・テロップのエフェクト・モーション・立ち絵・カメラ・FX・ビジュアル・ルックのどれかを全部消す |
| **タイミング全消去** | 左パネル「歌詞」。全トラックの記録を消す（素材と歌詞の文章は残る） |

どれも `Ctrl+Z` で戻せます。
