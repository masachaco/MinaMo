# 15. スマホ版（試作）

スマホ版は、キーボードの代わりに **画面のパッド** を押して演奏・録音するページです。PC 版と同じ場所の `mobile/` にあります。

- スマホ版：<https://masachaco.github.io/MinaMo/mobile/>（ローカルでは <http://localhost:5178/mobile/>）

まだ試作です。PC 版と同じプロジェクト・同じ演出を使いますが、できることは演奏と録音が中心です。

## 画面

上から順に並んでいます。

| 場所 | 内容 |
|---|---|
| 上部 | 再生位置（時間・小節）、元に戻す / やり直し、☰ メニュー |
| プレビュー | できあがりの映像 |
| 案内 | 歌詞トラックでは次に入れる行（▲▼ で行を移動、文字を押すとそこから）、テロップトラックでは次に出すテロップ、ほかのトラックでは今の状態 |
| シークバー | 再生位置の移動 |
| 再生ボタン | 先頭へ・1小節戻る・再生 / 停止・1小節進む、**● REC**（選んでいるトラックを録音）、重ね録り / 上書きの切り替え |
| トラック | 歌詞・テロップ・立ち絵・カメラ・FX・ビジュアル・ルック（横にスクロール）。開いたときは FX |
| パッド | 選んでいるトラックの演出。PC 版のキーと同じものが並びます。今の状態に当たるパッドは枠が光ります |

## 使い方

1. ☰ → 「曲を読み込む」で曲を選びます（初めて開いたときはデモが入っています）。立ち絵・背景も ☰ から追加できます。
2. ☰ → 「歌詞」に歌詞を書いて「歌詞を反映」を押します。
3. トラックを選び、**● REC** を押して、歌に合わせてパッドを押します。
   - 歌詞トラック：歌に合わせて1文字ずつ表示したい場合は「1文字ずつ」、1行ずつ表示したい場合は「1行ずつ」（単語ごとなら「単語ごと」）。間違えたら「直前の入力を取り消す」。
   - テロップトラック：「次のテロップ」を押した長さがテロップの長さになります。
   - FX トラック：⏵ の付いた FX は押している間だけ続きます。
4. **■ 停止** で録音を終えます。録り直すときは ↶ で戻すか、「上書き」に切り替えて同じ区間を録ります。
5. ☰ → 「動画を書き出し」で MP4 を保存します。

REC していないときにパッドを押すと、再生中なら試し弾き（画面に出るだけで記録されない）、止まっているときは何も起きません。

## PC 版との違い

- タイムラインでの細かい編集（移動・削除・ダブルクリックで置く）、インスペクタ、スタイルや見た目の設定、テロップの一覧、MMD、プラグインの読み込みは PC 版で行います。
- プロジェクトはブラウザに保存されるので、同じブラウザなら PC 版のページとスマホ版のページで共通です。別の端末へは ☰ → 「保存 (.json)」と「読み込み」で移します（曲や画像は入れ直してください）。
- 動画の書き出しは WebCodecs に対応したブラウザが必要です。端末やブラウザによっては書き出せないことがあります。
