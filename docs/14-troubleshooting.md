# 14. 困ったとき・FAQ

## 再生・音

**音が出ない**
- ページのどこかを一度クリックしてから再生してください（ブラウザは操作前の自動再生を止めます）。
- 曲が読み込めているか、左パネル「楽曲」に曲名が出ているか確認してください。

**叩いたタイミングがいつもずれる**
- Bluetooth のイヤホン・スピーカーは音が遅れます。できれば有線で。
- 左パネル「入力 → 入力遅延補正」で直します（記録が遅れるなら正の値）。測り方は [11. 上級テクニック](11-advanced.md#歌に合わせて表示するコツ)。

**再生速度を変えたらしばらく反応しない**
- 各速度の初回だけ、音程を保つための準備に数秒かかります（「準備中」と出ます）。2回目からはすぐ切り替わります。

**止めると戻ってしまう / 戻ってほしい**
- 上部バーの ▶ の横で「↩ 開始位置に戻る」「■ その場で止める」を切り替えます。

## キー・録音

**キーを押しても何も起きない**
- 入力欄（歌詞・BPM など）にカーソルがあると、キーは演出になりません。プレビューなどをクリックしてから押してください。
- 停止中のキーは記録されません。REC（`Shift+R`）するか、再生して試し弾きを。
- 歌詞の `Space` / `N` / `Enter` / `X` と、テロップの `Space` / `X` は REC 中だけ効きます。
- 押したいキーが選んでいるトラックのものか確認してください（上部のタブ、`Tab` で切替）。

**停止中にキーを押したら、選んでいた要素が変わった**
- 仕様です。要素を選んでいるとき、停止中のキーはその要素の値を書き換えます。`Ctrl+Z` で戻せます。選択を外すには、タイムラインの空いている所をクリック。

**REC 中にトラックを切り替えられない**
- REC 中は切り替えられません。`Esc` で止めてから。

**プラグインで足した FX・エフェクト・モーションにキーがない**
- 空いているキーの数だけキーに入ります（FX は `C` `V` `B` `N` `M`、エフェクトは `I` `O` `P` `[` `]`（歌詞・テロップは `U` も）、モーションは `J` `K` `L`（立ち絵は `H` も））。それより多い分はキーパネルのクリックか、タイムラインのダブルクリックのメニューから置けます。
- エフェクト・モーションは、プラグインが要素を絞っていると（例：立ち絵専用）、そのトラックにしか出ません。

**前に録ったものが消えた**
- REC の方式が「上書き」になっていると、録った区間の記録が差し替わります。キーパネルの上で「重ね録り」に戻してください。`Ctrl+Z` でテイクごと戻せます。

## 見た目

**歌詞が小さい・思った所で改行されない**
- 行を積むスタイルでは、歌詞に `/` を書くとそこで改行されます（[3. 歌詞](03-lyrics.md#行の分かれ方kinetic-など)）。
- キャラが中央にいると、歌詞は下の狭い所に出ます。キャラを左右に置くと大きく出せます。

**文字が背景に溶けて読めない**
- 背景を暗くする（ルックトラックの明るさ、左パネル「背景の暗さ」）、パレットを変える、[文字色の部分反転](06-look.md#文字色の部分反転) をオンにする。

**白い光が入る**
- ルックの切替のトランジションです。`Shift+数字` で切り替えるか、インスペクタで「なし」に。

**歌詞・テロップのエフェクトがステッカーや帯にかからない**
- 仕様です。歌詞・テロップのエフェクト（影・縁取り・グロー…）は文字だけにかかり、ステッカーや帯などの下地はそのまま残ります。

## 素材・MMD

**「見つからない素材」と出る**
- .json を別のブラウザや PC で読み込むと、素材のファイルは入っていません。曲・背景・立ち絵・MMD モデルを入れ直してください。
- 立ち絵は、左パネルのカードの「差し替え」（カードへのドロップでも可）で入れ直すと、録音した切替がそのまま使えます。

**MMD モデルが真っ白 / テクスチャがない**
- モデルファイル1つではなく、テクスチャの入った **フォルダごと** 入れてください。

**MMD の髪やスカートの動きが不自然**
- モデルの枠の「揺れもの（髪・スカート）」をオフにしてください（スプリングボーンによる近似なので、モデルによって合わないことがあります）。

**MMD のカメラ VMD が読めない / 立ち絵にならない**
- カメラだけの VMD は立ち絵にはならず、立ち絵に「付ける」ものです。モーションと一緒に追加するか、立ち絵カードの「＋ カメラ VMD」から。

## 書き出し

**「書き出し開始」が押せない / WebCodecs 非対応と出る**
- Chrome か Edge を使ってください。

**書き出しが遅い**
- 解像度や FPS を下げる、範囲を短くして試す、MMD の揺れものを切る、など。1フレームずつ正確に描くため、曲の長さより時間がかかることがあります。

**書き出した MP4 の音が出ない（QuickTime など）**
- 環境によって音声が Opus になっています。WebM で書き出すか、ffmpeg で AAC に変換してください（[9. 書き出し](09-export.md#知っておくこと)）。

## データ

**作ったものが消えた**
- ブラウザの閲覧データを削除すると消えます。別のブラウザ・別のアドレスで開いた場合も空に見えます。大事なプロジェクトは左パネル「プロジェクト → 保存 (.json)」で残してください。

**デモをもう一度見たい / デモを消して自分のを作りたい**
- 左パネル「プロジェクト → デモを開く」でデモに戻せます（`Ctrl+Z` で元のプロジェクトへ）。空から作るときは右上の「新規」。

**チュートリアルをもう一度見たい**
- 右上の「？」から。デモ以外のプロジェクトでも動きますが、歌詞の行などはデモを開いてからのほうが分かりやすいです。

**プラグインを入れたらエラーが出る**
- エラーの内容がトーストに出ます。左パネル「プロジェクト → プラグイン」の一覧から「削除」して、再読み込みしてください。
