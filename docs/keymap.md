# キー一覧

キーは **いま選んでいるトラック**（上部のタブ、`Tab` で切替）ごとに意味が変わります。キーパネル（右上）にも同じものが表示され、クリックしても押せます。
キーボード配列（JIS / US）や IME のオン・オフに関係なく、キーの物理的な位置で判定します。

## 全トラック共通

| キー | 動作 |
|---|---|
| `Space` | 再生 / 停止（歌詞・テロップトラックの REC 中はタップ） |
| `Shift+R` | REC 開始 / 終了 |
| `Tab` / `Shift+Tab` | トラック切替（REC 中は切り替えられない） |
| `Esc` | REC 終了・停止 |
| `←` `→` | 1拍戻る / 進む（`Shift` で1小節） |
| `Home` / `End` | 先頭 / 末尾へ |
| `Ctrl+Z` / `Ctrl+Shift+Z`・`Ctrl+Y` | 元に戻す / やり直す（REC 中は無効） |
| `Ctrl+S` | プロジェクトを .json で保存 |
| `Delete`・`Backspace` | 選択中の要素を削除（REC 中の `Backspace` は直前の入力の取り消し） |

- 停止中にキーを押しても何も記録されません（「再生中に押すと試せます」と出ます）。
- ただし要素を選んでいるときは、停止中のキーでその要素の値を書き換えます（[5. タイムラインで編集](05-editing.md)）。

## 歌詞

| キー | 動作 |
|---|---|
| `Space` | 歌に合わせて1文字ずつ表示：次の1文字を出す ※REC 中 |
| `N` | 単語（チャンク）ごとに表示：次のチャンクを出す ※REC 中 |
| `Enter` | 1行ずつ表示：次の1行を出す ※REC 中 |
| `X` | 表示中の歌詞を消す ※REC 中 |
| `1`〜`0` | 歌詞スタイル（KINETIC / GLITCH / NEON / EMOTIONAL / POP / IMPACT / MINIMAL / プラグイン…。ルック専用のプラグインは入らない） |
| `Q` `W` `E` `R` `T` | 歌詞のエフェクト（トグル）：影・縁取り・グロー・スライス・シルエット |
| `Y` | 歌詞のエフェクト：なし |
| `A` `S` `D` `F` `G` `H` | 歌詞のモーション：静止・バウンス・ゆらゆら・ふわふわ・ジャンプ・ブルブル |
| `I` `O` `P` `[` `]` `U` / `J` `K` `L` | プラグインのエフェクト / モーション |
| `↑` `↓` | 入力位置を1行戻す / 進める（停止中） |
| `Shift+↑` `Shift+↓` | 入力位置を1文字戻す / 進める（停止中） |

## テロップ

| キー | 動作 |
|---|---|
| `Space` | 一覧の次のテロップを出す ※REC 中（短く押すと型の既定の長さ、長押しでその長さ） |
| `X` | 表示中のテロップを消す ※REC 中 |
| `Q` `W` `E` `R` `T` | テロップのエフェクト（トグル）：影・縁取り・グロー・スライス・シルエット |
| `Y` | テロップのエフェクト：なし |
| `A` `S` `D` `F` `G` `H` | テロップのモーション：静止・バウンス・ゆらゆら・ふわふわ・ジャンプ・ブルブル |
| `I` `O` `P` `[` `]` `U` / `J` `K` `L` | プラグインのエフェクト / モーション |
| `↑` `↓` | 次に出すテロップを選ぶ（停止中） |

## 立ち絵

| キー | 動作 |
|---|---|
| `1`〜`9` | 立ち絵（キャラ）切替。MMD はポーズ／モーションごとに1つ |
| `0` | 隠す |
| `-` | キャラ：オート |
| `A` `S` `D` `F` | 位置：左・中央・右・2人 |
| `G` | 位置：オート |
| `Q` `W` `E` `R` `T` | エフェクト（トグル）：影・縁取り・グロー・スライス・シルエット |
| `Y` / `U` | エフェクト：なし / オート |
| `Z` `X` `C` `V` `B` `N` | モーション：静止・バウンス・ゆらゆら・ふわふわ・ジャンプ・ブルブル |
| `M` | モーション：オート |
| `I` `O` `P` `[` `]` / `J` `K` `L` `H` | プラグインのエフェクト / モーション |

エフェクトとモーションは歌詞・テロップ・立ち絵で共通です（歌詞・テロップのモーションは `N` `X` がタップ用なので A行）。

## カメラ

| キー | 動作 |
|---|---|
| `A` `S` `D` `F` `G` `H` `J` | フレーミング：ワイド・全身・膝上・バスト・アップ・パンアップ・ダッチ（`Shift` 付きでスムーズに移動、なしはカット） |
| `K` | フレーミング：オート |
| `Q` `W` `E` `R` `T` `Y` `U` `I` | 動き：固定・ズームイン・ズームアウト・パン・上昇・手ブレ・ロール・ビートズーム |
| `O` | 動き：オート |
| `Z` `X` `C` `V` `B` | プラグインのフレーミング（足した順。プラグインが希望したキーが空いていればそこへ） |
| `P` `[` `]` `N` `M` `L` | プラグインの動き（同上） |

## FX

| キー | FX | | キー | FX |
|---|---|---|---|---|
| `Q` | フラッシュ | | `A` | モザイク ⏵ |
| `W` | シェイク | | `S` | 色相回転 ⏵ |
| `E` | ズームパンチ | | `D` | スピン |
| `R` | グリッチ ⏵ | | `F` | 画面バウンス ⏵ |
| `T` | ネガ反転 ⏵ | | `G` | カラーフラッシュ |
| `Y` | ストロボ ⏵ | | `H` | シネスコ ⏵ |
| `U` | 集中線 ⏵ | | `J` | VHS ⏵ |
| `I` | 衝撃波 | | `K` | 傾き |
| `O` | ミラー ⏵ | | `L` | 紙吹雪 |
| `P` | ブラックアウト ⏵ | | `Z` | ビートリング ⏵ |
| `[` | モノクロ ⏵ | | `X` | 砂嵐 ⏵ |
| `]` | RGBシフト | | | |

⏵ = 長押しできる FX。短く押すと既定の長さ、長く押すとその長さまで延びます。プラグインの FX は空いているキー（`C` `V` `B` `N` `M`）に割り当てられ、それより多い分はキーパネルのクリックやタイムラインのダブルクリックのメニューから置けます。

## ビジュアル（オーディオビジュアライザー）

| キー | 動作 |
|---|---|
| `1`〜`9` | 種類：バー・ミラーバー・サークル・波形・ドットEQ・リング・パーティクル・ブロブ・フレーム |
| `0` | 消す |
| `Q` `W` `E` `R` `T` | 位置：下・中央・上・キャラの周り・全面 |
| `A` `S` `D` `F` `G` | 色：アクセント・サブ・文字色・グラデーション・レインボー |
| `Z` `X` `C` | 大きさ：小・中・大 |
| `V` / `B` | キャラの後ろ / 前 |

## ルック

| キー | 動作 |
|---|---|
| `1`〜`0` | ルックスタイル（`Shift+数字` でトランジションなしに切替。歌詞スタイル専用のプラグインは入らない） |
| `Q`〜`P` | 背景1〜10 |
| `[` / `]` | 背景なし / オート（セクションごとに順番） |
| `A`〜`K` | パレット：Midnight・Cyber・Sakura・Sunset・Lemon・Ocean・Mono・Paper |
| `N` `M` | パレット：プラグインで足したもの（最初の2つ） |
| `L` | パレット：オート（プロジェクトの設定） |
| `Z` `X` `C` `V` | 背景の明るさ：明るい・標準・暗め・真っ暗 |
| `B` | 明るさ：オート（プロジェクトの設定） |

## マウス（タイムライン）

| 操作 | 動作 |
|---|---|
| クリック | その時刻へ移動（要素の上なら選択） |
| ドラッグ | 要素を移動（拍にスナップ。`Alt` で解除） |
| ダブルクリック | その時刻に置けるもののメニュー |
| 右クリック | 要素を削除 |
| ホイール / `Ctrl+ホイール` | スクロール / ズーム |
| 中ボタンドラッグ | 表示範囲を動かす |
| トラック名をクリック | そのトラックを録音対象にする |
