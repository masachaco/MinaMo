# 11. 上級テクニック

## おすすめの作業の順番

トラックは何周でも重ねられるので、**大きなものから細かいものへ** 1本ずつ録ると迷いません。

1. **拍を合わせる**：BPM と1拍目を合わせ、メトロノームをオンにして曲とクリックが揃うか確認。ここがずれると後の全部がずれる。
2. **歌詞を叩く**：まず全部を `Space` / `N` / `Enter` で入れる。難しいところは 0.75× に落とす。あとで一括クオンタイズやドラッグで整える。
3. **ルックで曲の構成を作る**：イントロ・Aメロ・Bメロ・サビの頭でルックを切り替え、セクションの色を決める。同じ流れの中は `Shift+数字`（トランジションなし）で。
4. **歌詞スタイル**：サビは IMPACT、しっとりした所は EMOTIONAL、情報量を減らしたい所は MINIMAL…と、歌詞の動きで山と谷を作る。決め台詞の1行だけはインスペクタで「この行の歌詞スタイル」。スタイルを変えずに味付けしたい所は、歌詞のエフェクト（`Q`〜`T`：影・グローなど）やモーション（`A`〜`H`：バウンス・ゆらゆらなど）を重ねる。
5. **立ち絵**：フレーズの頭でキャラやポーズを切り替える。MMD のモーションは「拍に合わせる」で踊らせる。
6. **カメラ**：小節の頭でカット、ゆったりした所は `Shift` でスムーズに。サビでアップ、間奏でワイドなど。
7. **FX**：キメやドラムのアクセントに。1小節に何発も入れず、ここぞという所に絞る。
8. **ビジュアル・テロップ**：間奏やイントロを埋める。タイトルとクレジットを置く。
9. **書き出しの試し**：サビだけなど短い範囲を 30fps で書き出して、見え方と所要時間を確かめてから本番。

## 歌に合わせて表示するコツ

- **押すのは子音の立ち上がり**。母音の伸びで押すと遅れて見える。
- 速いフレーズは `N`（単語ごと）や `Enter`（1行ずつ）でまとめて出し、見せたい文字だけ `Space`（1文字ずつ）で入れ直す。残りは自動で間を埋める。
- **いつも遅れる・早い** なら入力遅延補正で直す。測り方：メトロノームをオンにして拍に合わせて叩き、タイムラインで拍線からのずれを見る（遅れていれば正の値を入れる）。
- REC の前に **試し弾き**（REC せずに再生してキーを押す）で指を慣らす。
- 「↩ 開始位置に戻る」のまま、`Shift+R` → 叩く → `Esc` を繰り返すと同じ区間を何度でも録り直せる。気に入らなければ `Ctrl+Z` でテイクごと取り消し。
- 録り直しは **パンチイン**：途中から叩き直すと、それ以降の古いタイミングは自動で消える。

## 重ね録りと上書きの使い分け

- 既定の **重ね録り** は、演出を1周ずつ足していくのに向いています。
- ある区間の FX やカメラを **やり直したい** ときだけ「上書き」に切り替えて、その区間を REC し直すと、区間内の古い記録が消えて差し替わります。
- 1つだけ直したいなら、REC せずに **その ◆ を選んでキーを押す**（値の書き換え）か、ドラッグで移動するのが速いです。

## マウスとキーの合わせ技

- 曲を止めて見ながら置きたい一発（ブレイクの暗転、ラストのホワイトアウトなど）は、**ダブルクリックでメニューから** 置き、ドラッグで拍に合わせる。
- 置いてから「やっぱり別の FX」なら、◆ を選んでキーを押すだけ。
- ドラッグ中に `Alt` を押すとスナップが外れ、拍の間に置けます。

## 見やすさ

- 明るい背景や写真の背景では、ルックトラックの明るさ（`X` 標準・`C` 暗め）や、[文字色の部分反転](06-look.md#文字色の部分反転)（弱〜中）を使う。
- 歌詞の表示領域はキャラの位置で決まります。キャラが中央のときは歌詞が下に寄るので、長い歌詞の区間はキャラを左右に置くと大きく出せます。
- 行を積むスタイルで思った通りに改行したいときは、歌詞に `/` を書く。

## 重いとき

- 左パネル「出力 → プレビュー画質」を下げる（書き出しには影響しない）。
- MMD の揺れもの（物理）は、録音中だけオフにしてもかまいません（オンに戻せば書き出しに反映）。
- 背景動画は解像度の低いものを使う。
