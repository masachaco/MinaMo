# 2. 画面の見方

```
┌──────────────────────── 上部バー ─────────────────────────┐
│ トラックのタブ │ ⏮ ▶ 停止時の動き 速度 │ ● REC │ 時刻 │ ↶ ↷ 書き出し │
├──────────┬──────────────────────────┬───────────┤
│ 左パネル │ プレビュー                │ キーパネル │
│ (設定・  │                          │ (PERFORM)  │
│  素材)   ├──────────────────────────┤───────────┤
│          │ プロンプター（次に叩く文字）│ インスペクタ│
├──────────┴──────────────────────────┴───────────┤
│ タイムライン（トラックごとの記録）                           │
└──────────────────────────────────────────────────┘
```

## 上部バー

| 部品 | 役割 |
|---|---|
| **トラックのタブ** | 歌詞・テロップ・立ち絵・カメラ・FX・ビジュアル・ルック。選んだトラックがキーの対象で、REC で記録される先。`Tab` で切替 |
| **⏮** | 先頭へ |
| **▶ / ❚❚** | 再生 / 停止（`Space`） |
| **↩ 開始位置に戻る / ■ その場で止める** | 停止したときの動き。既定は「戻る」（[4. トラックと録音](04-recording.md#停止したときの動き)） |
| **1×** | 再生速度 0.5〜1.5 倍（練習用） |
| **● REC ○○** | 選んだトラックの REC（`Shift+R`）。REC 中は赤く光る |
| **時刻** | 再生位置と小節・拍 |
| **拍の点滅** | 小節内の拍 |
| **新規** | 空のプロジェクトにする（デモや今のプロジェクトを片付ける。元に戻せない） |
| **？** | チュートリアル（[1. はじめに](01-quickstart.md#まずはデモを見る)） |
| **↶ ↷** | 元に戻す / やり直す |
| **書き出し** | 動画ファイルへ（[9. 書き出し](09-export.md)） |

## 左パネル

上から順に、折りたためる欄が並んでいます。

| 欄 | 中身 |
|---|---|
| **楽曲** | 曲ファイル、タイトル、アーティスト、BPM（`TAP` で推定）、拍子、1拍目（「現在位置」で合わせる）、メトロノーム |
| **歌詞** | 歌詞の入力欄、書き方のヒント、「タイミング全消去」 |
| **テロップ** | テロップ一覧の入力欄（[7. テロップ](07-telop.md)） |
| **背景・立ち絵** | 背景画像・動画の一覧、立ち絵の一覧と調整（顔の位置・大きさ・横／縦オフセット・反転・使う/使わない・画像の差し替え）、MMD モデル（[8. 立ち絵と MMD](08-characters.md)） |
| **ルック** | パレット、録音していない区間の歌詞スタイルとルック、背景の暗さ、文字色の部分反転、FX 強度、オート演出の間隔、演出シード、HUD |
| **入力** | 歌詞クオンタイズ、イベントスナップ、入力遅延補正、自動消去（[3. 歌詞](03-lyrics.md)） |
| **出力** | 解像度、FPS、プレビュー画質 |
| **プロジェクト** | 新規、.json で保存 / 読み込み、デモを開く、チュートリアル、プラグインの読み込み |

入力欄に文字を打っている間は、キーが演出に化けることはありません（BPM の数字を打っても大丈夫）。

## プレビュー

いまの時刻の完成画面です。書き出しと同じ描画なので、見えている通りに書き出されます。
重いときは左パネル「出力 → プレビュー画質」を下げてください（書き出しの画質には影響しません）。

## プロンプター（プレビューの下）

選んでいるトラックの「次に何が起きるか」と「いまの状態」を表示します。

- **歌詞トラック**：次に `Space` / `N` / `Enter` で出る文字がハイライトされます。スライダー（文字 / 行単位）や行内の文字クリックで入力位置を選べます。「再生位置に追従」「⏮ 頭出し」もここ（[3. 歌詞](03-lyrics.md#入力位置)）。
- **テロップトラック**：次に出すテロップ。クリックで選べます。
- **その他**：いまのキャラ・位置・カメラなどの状態。

## キーパネル（右上、PERFORM）

選んでいるトラックで使えるキーの一覧です。いま有効な値が光ります。クリックでも押せます。
上に REC の方式（**重ね録り** / 上書き）の切替と、トラックの使い方のヒントがあります。

## インスペクタ（右下）

タイムラインで選んだ要素（歌詞の行・文字、テロップ、各イベント）の時刻や値を編集します（[5. タイムラインで編集](05-editing.md#インスペクタ)）。

## タイムライン（下）

上から **ルーラー（小節）・LYRICS・TELOP・CHARA・CAMERA・FX・VISUAL・LOOK・AUDIO（波形）** の行が並びます。

- LYRICS の上の細い帯は歌詞スタイルの区間、LOOK の上の帯はルックの区間です。
- LYRICS と TELOP の下の細い帯は、その要素のエフェクト（上半分）・モーション（下半分）がかかっている区間とその切替（◆）です。
- ◆ が記録されたイベント、帯がテロップや表示中の歌詞です。
- 行の名前をクリックすると、そのトラックが録音対象になります。
- ツールバー：ズーム（− +）、全体表示、追従（再生位置を追いかける）、スナップ、一括クオンタイズ、トラック消去。

操作は [5. タイムラインで編集](05-editing.md) を参照してください。
