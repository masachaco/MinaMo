# 7. テロップ

テロップは歌詞とは別の文字情報です（曲名、歌い手の名前、字幕、章タイトル、クレジットなど）。一覧を書いて、テロップトラックで出すタイミングを録ります。

## 一覧の書き方

左パネル「テロップ」の欄に、**1行 = 1テロップ** で書きます。

```
[タイトル] {title} | {artist}
[名前] 水面みなも | Vocal
[字幕] ここから2番が始まります | Verse 2
[チャプター] CHORUS | 02
[クレジット] Music: masa / Lyrics: masa / Illust: someone | STAFF
```

| 書き方 | 意味 |
|---|---|
| `[型]` | テロップの型（下の表）。省略すると字幕 |
| 本文 | メインの文字 |
| `\|` の後ろ | サブの文字 |
| `{title}` `{artist}` | 左パネル「楽曲」のタイトル・アーティストに置き換わる |
| `#` で始まる行 | コメント |

## 型

| 型（書き方） | 見た目 | 既定の長さ |
|---|---|---|
| `[タイトル]` | 曲名カード（ルックスタイルのタイトルカード） | 4小節 |
| `[名前]`（ネーム・ロワー） | 画面下の名前の帯（ロワーサード） | 4小節 |
| `[ラベル]`（コーナー） | 隅の小さなラベル | 8小節 |
| `[字幕]`（キャプション） | 下の字幕の箱 | 2小節 |
| `[チャプター]`（見出し） | 画面中央の章タイトル | 2小節 |
| `[クレジット]`（スタッフ） | 右側のスタッフロール。本文を ` / ` で区切ると1行ずつ | 8小節 |

`[title]` のように id で書いても同じです。プラグインで足した型も、名前か id で書けます。

## 出し方

1. テロップトラックを選び、`Shift+R` で REC。
2. 出したい瞬間に `Space`。
   - **短く押す**：型の既定の長さだけ表示
   - **長押し**：押していた長さだけ表示
3. 表示中のものを早めに消すときは `X`。

- 次に出すテロップはプロンプターに表示されます。`↑` `↓`（停止中）やクリックで選べます。「再生位置に追従」がオンなら、REC を始めたときに再生位置の後ろの未配置のものから出します。
- **マウスで置く**：タイムラインの TELOP 行をダブルクリック → 一覧から選ぶ（[5. タイムラインで編集](05-editing.md#マウスで置くダブルクリック)）。
- 帯をドラッグで移動、帯の右端のドラッグで長さを変えられます。インスペクタでは開始・長さ・型を変えられます。

## エフェクトとモーション

テロップにも、立ち絵・歌詞と同じエフェクトとモーションをかけられます。テロップトラックで録ります。

| キー | 内容 |
|---|---|
| `Q` `W` `E` `R` `T` / `Y` | エフェクト（トグルで重ねがけ）：影・縁取り・グロー・スライス・シルエット / なし |
| `A` `S` `D` `F` `G` `H` | モーション（1つ選ぶ）：静止・バウンス・ゆらゆら・ふわふわ・ジャンプ・ブルブル |

- その時刻に表示中のテロップ全部にかかります。エフェクトは文字に（帯や箱はそのまま）、モーションは型ごとの位置（名前なら左下、クレジットなら右側…）を軸に動きます。
- タイムラインでは TELOP の下の細い帯に ◆ が並びます。
- プラグインで足したものは `I` `O` `P` `[` `]` `U` / `J` `K` `L` に入ります。

## タイトルカード

新しいプロジェクトには、0秒から4小節の `[タイトル] {title} | {artist}` が最初から置かれています。普通のテロップなので、動かすのも消すのも自由です。

## 読みやすさ

テロップの帯や箱は「文字の下地」として描かれるので、[文字色の部分反転](06-look.md#文字色の部分反転) をオンにすると、背景と同化する文字だけ塗りが切り替わります。
