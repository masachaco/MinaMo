# 9. 書き出し

右上の **「書き出し」** から、動画ファイルにします。

## 設定

| 項目 | 内容 |
|---|---|
| 解像度 | 左パネル「出力」で選ぶ：1920×1080（16:9）・1280×720・3840×2160（4K）・1080×1920（縦 9:16）・1080×1080（1:1） |
| FPS | 左パネル「出力」：30 / 60（既定 60） |
| 形式 | **MP4**（H.264 / AAC）または **WebM**（VP9 / Opus） |
| 画質 | 高（既定）・最高・中（軽量） |
| 開始 / 終了（秒） | 書き出す範囲（既定は曲全体） |

「書き出し開始」を押すと、1フレームずつ描いてエンコードします。進み具合と残り時間の目安が表示され、終わるとファイルがダウンロードされます。「閉じる」で中止できます。

## 知っておくこと

- **見えている通りに書き出されます**。プレビューと同じ描画を、指定の解像度で1フレームずつ行います。
- **時間**：PC の性能・解像度・FPS・演出の重さ（MMD、ビジュアライザー、ぼかしの多いスタイル、歌詞・テロップのエフェクト）で大きく変わります。曲の長さより時間がかかることもあります。試しに短い範囲や 30fps で書き出してみると目安になります。
- **再生速度の設定は関係ありません**。いつも元の速さで書き出します。
- **音声**：MP4 は AAC を優先し、使えない環境（Chromium など）では Opus になります。Opus 入りの MP4 は一部のプレイヤー（QuickTime など）で再生できないので、そのときは WebM で書き出すか、ffmpeg で音声を変換してください：
  ```bash
  ffmpeg -i input.mp4 -c:v copy -c:a aac -b:a 192k output.mp4
  ```
- 解像度によっては使える映像コーデックがないことがあります（古い PC で 4K など）。その場合はエラーになるので、解像度を下げてください。
- 書き出し中は再生やキー入力をしないでください。

## 縦動画・正方形

左パネル「出力 → 解像度」を 1080×1920 や 1080×1080 にすると、プレビューもその比率になり、歌詞の配置やキャラのフレーミングも自動で合わせます。見え方が変わるので、書き出す前にプレビューで確認してください。
